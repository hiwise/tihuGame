# 鹈鹕快递实施计划
目标：离线角色车库、三图四车、送信结算和复玩。
架构：无运行时依赖；HTML、CSS 和 JavaScript 源码由 Node 构建脚本合并为 index.html。Canvas 绘制背景和路面，WebGL 绘制具有平滑法线的模型；无法启用 WebGL 时使用 Canvas 回退。
- [x] 角色与车库：姓名、公母、独立试穿、旋转预览、保存与恢复。
- [x] 赛道：珊瑚湾、落霞峡谷、霓虹港，以及各自的障碍和路线机制。
- [x] 载具：自行车、摩托车、驾驶舱赛车、滑板凳；不同控制和特殊动作。
- [x] 送达结算：成绩、挑战、外观奖励、重赛、个人幽灵。
- [x] 离线测试：三图四车全程、键盘与触控、档案恢复和构建可复现性。
