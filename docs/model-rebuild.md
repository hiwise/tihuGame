# 五项资产替换说明

参考图位于 `art/model-references`。游戏中的资产是参数化 WebGL 网格，由 `src/models.js`（角色、站姿和乘骑关节）和 `src/vehicles.js`（载具、材质和安装点）生成。它们不是把参考 PNG 贴到平面上，也不依赖图片文件运行。

| 资产 | 采用的基准与取舍 |
|---|---|
| 英雄鹈鹕 | 正面定 A 字翼臂与站姿，侧面定长喙及喉囊，独立披风不遮挡三视图。材质使用游戏实时着色，保留公母与换装。 |
| 自行车 | 侧视确定细胎、轮径、菱形车架和后架；前轮、前叉、车把同轴转向，曲柄与角色脚位置同步。 |
| 摩托车 | 以侧视的圆油箱、厚胎、排气、后悬挂和邮包为基准；翼臂跟随握把，脚对齐脚踏。 |
| 赛车 | 以侧视及俯视定车身和轴距；重做轮拱、灯组与尾翼。参考没有内饰，驾驶舱另行配色设计。 |
| 街式滑板 | 以俯、侧、底视定七层板边、翘头、板桥和四轮；无座。站板姿态配合按住加速时的蹬地与 Shift 豚跳。 |

在「角色」页点击「三视图」按顺序查看正、侧、背。转回自由视角可查看随速度摆动的披风。自行车和滑板的赛道动作推荐用 C 切到侧后视角查看。旧档的姓名、穿搭与其他载具纪录保留；旧滑板凳成绩不会计入街式滑板。
