# 鹈鹕快递 · 海湾邮局

用浏览器打开 **index.html** 即可游玩。游戏不需要服务器、安装包或网络连接；把这一份 HTML 单独复制到其他电脑也可以打开。角色和成绩保存在当前浏览器，移动文件或更换浏览器时，旧存档不一定会随文件迁移。

- 创建邮差档案，选择公鹈鹕或母鹈鹕，点选时会摆姿势、敬礼并说 “Yes!”。在试衣间拖动旋转、试穿和混搭；点「三视图」可对照正、侧、背面。「飞行邮差」采用参考图的修长 A 字姿态，红色披风可单独选配。
- 地图简报和载具检阅延续暗金大厅风格，地图页可直接切换预览载具和角色姿态。五张地图各有两项挑战：珊瑚湾栈道、落霞峡谷落石、霓虹港雨夜闸门、翡翠雨林积水和瀑布桥、银脊山道冰面与隧道。
- 四种载具默认开放：自行车兔跳、摩托压弯、赛车双仪表驾驶舱、自动挡位及氮气、街式滑板蹬地和豚跳。
- 送达后查看评级与纪录。刷新纪录后，可在同一地图、同一载具下追逐个人幽灵。

在车库点击「雨林追逐赛」即可直接参赛。倒计时最后半秒按住加速，跟车补氮，弯前减速后贴内侧走线，Shift 冲刺。比赛记录与派送记录分开保存。

方向键 / WASD 行驶，Shift 使用载具特技，空格使用补给道具，C 切换非赛车视角，P / Esc 暂停，M 切换音效。触屏上有对应的驾驶和特技按钮。

## 工程

- `src/page.html`、`src/game.css`：页面与样式。
- `src/config.js`、`src/garage.js`、`src/lobby.js`：配置、档案、试衣间和车库。
- `src/renderer.js`、`src/models.js`、`src/vehicles.js`：世界坐标投影、路面与角色共用的 WebGL 深度缓冲、程序化沥青与水雪材质、平滑着色及 Canvas 回退。
- `src/routes.js`、`src/game.js`、`src/cockpit.js`、`src/race.js`：赛道、障碍、驾驶、挑战与结算。
- `build.cjs`：把上述源码合并成可直接打开的 `index.html`，无需安装 npm 依赖；敬礼语音由 `art/audio/yes.wav` 内嵌。
- `tests/browser.cjs`：断网 Chrome 测试。默认使用 Windows 的标准 Chrome 路径；可通过 `CHROME_BIN` 指定其他路径。

修改源码后，在工程目录执行：

```powershell
node build.cjs
node tests/browser.cjs
```
